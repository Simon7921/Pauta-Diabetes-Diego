# V18 · Cambio de sensor de Diego

- Primera fecha: **24 de noviembre de 2026**.
- Recurrencia: **14 días**; posteriores: 8 de diciembre, 22 de diciembre, etc.
- Aviso destacado dentro de Inicio al faltar **3, 2, 1 o 0 días**.
- La fecha se puede modificar con «Cambiar fecha» y queda guardada en este dispositivo.
- Calcula diferencias por días calendario, sin depender de cambios de horario.
- Se actualiza cada minuto mientras la aplicación está abierta y al regresar a ella.

**Limitación:** no envía notificaciones push si la aplicación está cerrada. Para recibir avisos fuera de la app se requeriría configurar notificaciones push o alarmas de calendario. Un cambio anticipado de sensor requiere ajustar manualmente la próxima fecha.
